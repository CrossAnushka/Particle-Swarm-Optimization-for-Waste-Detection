\section*{Data and Code Availability}
All the data used in this study are publicly available. \genone is based on the Kaggle dataset ``Garbage Detection -- 6 Waste Categories''~\cite{viswaprakash2024garbage} (CC BY 4.0). For \gentwo, TACO~\cite{proenca2020taco} (CC BY 4.0) and the Humans in the Loop Recycling dataset~\cite{hitl2026recycling} (CC0) were added. The Indian test set was prepared from DWSD~\cite{ali2025dwsd} (CC BY 4.0), which can be downloaded from Mendeley Data at \url{https://doi.org/10.17632/gr99ny6b8p.1}. The code, the split file, the search logs and the result files are provided in the project repository at \url{https://github.com/CrossAnushka/Particle-Swarm-Optimization-for-Waste-Detection}, along with the dataset-build configuration that maps each source to the shared classes. The trained weights of all six models (three arms for each of the two generations) are also included in the repository under \texttt{app/models/} (\genone) and \texttt{app/models/gen2/} (\gentwo).
